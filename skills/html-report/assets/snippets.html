Interactive snippets — working demo

Four building blocks for reports that hand work back. Try each below; lift the matching <section> + script into your page.

1 · Copy selected as prompt / JSON

Filter/select rows, copy paste-ready text for the next Claude turn. Always flash a confirmation — silent clipboard writes read as broken buttons.

DateSourceItem

2 · URL-hash view state + "Copy view link"

Filter state lives in location.hash so any view is one copyable URL — the basis for cross-artifact evidence links. Type a filter, watch the URL, copy it, reopen: state restores.

3 · Feedback — autosave, server-or-download export

Debounced autosave 800 ms after the last keystroke. Export tries POST /api/feedback (live server mode) and falls back to downloading feedback.json when no server is present — one code path, degrades gracefully.

4 · Deep link — hand it to Claude Code

claude-cli://open opens a new Claude Code terminal with the prompt pre-filled, never auto-sent. Max 5,000 chars in q — for long runbooks link to a skill: q=/my-skill args. (Stripped on GitHub-rendered pages; fine in local/hosted HTML.)
